## Verification and outstanding prerequisites

The live probe found two callback defects and a deployment preflight defect. The startup script treated a comment containing `CHANGE_ME` as a credential placeholder; it now checks assignment lines. LangChain's `name=` callback argument collided with the wrapper's own parameter; the wrapper now uses `event_name`. Langfuse SDK 4 calls the custom mask with `data=`; the mask now accepts that documented keyword. The callback and mask corrections each had a failing focused test before the fix, followed by `9 passed` in `tests/observability/test_tracing.py`.

Independent review also found that a second `-Action Start` was rejected as a port conflict. Against the running stack, the old script failed on port 3000; after the fix, the same command exited 0 and Compose reported all six services running. The script now distinguishes this project's published loopback ports from unrelated listeners. The actual stopped-service SSE probe above closes the review's streaming evidence gap.
