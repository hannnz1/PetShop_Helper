## 实施裁定与验收边界

- 上游配置：本机 `.env` 使用 `https://api.openai.com/v1` 和 `gpt-4o-mini`；其他兼容服务须自行验证流式和结构化输出。
- 密钥字段：实施统一使用 `CHAT_API_KEY`；本机密钥只保存在被 Git 忽略的 `.env`，未提交或展示。
- 配置范围：本章只引入 `CHAT_*`，EMBED/RERANK 留给后续章节。
- token 预算：system、本轮输入及完整历史轮次均计入预算；超长本轮返回 422，估算不等同供应商精确 tokenizer。
- 结构化输出：默认 JSON mode，离线 MockTransport 已确认不发送 tools；真实 OpenAI 上游的五条标注样例已运行。
- 执行环境：已提供 Bash 和 Windows PowerShell 启动/验收入口。
- 验证范围：配置在应用启动时读取；真实两轮对话与 Prompt 标注样例已运行。抽样评估不能保证模型每次措辞相同。
- 提交署名：原稿指定其他助手的 Co-Authored-By，作为原文保留，不视为本次整理的真实署名；实施提交时应采用真实贡献者信息。

第 1 章接口验收已通过；`expected_solution` 的保养建议遗漏记录为后续质量改进项，不影响固定字段和本章三项验收标准。
