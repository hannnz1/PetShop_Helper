严格工具集合匹配：**9/9**；“邮费”原词 + FAQ 工具成功 + 空命中：**通过**。评估脚本现在分别报告这两个结论，若模型自行改写为“运费”或工具调用失败，漏召回判定不会通过。

浏览器实测：物流、退货政策、“邮费”三个场景均显示对应工具徽章；物流回答注明模拟数据，退货答出 7 天；“邮费”回答承认未检索到规则。同一浏览器会话追问 1001 可续接，点击“新对话”清除当前会话标识。Markdown 的加粗与链接能呈现，输入的原始 `<img>` 不会成为 DOM 元素。

质量边界：虽然 Prompt 要求 FAQ 未命中时不推测运费影响因素，第三次真实抽样和浏览器抽样仍有一次各自补充了未经 FAQ 支持的泛化因素。工具选择 9/9 不能解释为全部自然语言答案 9/9 合格。当前第 2 章明确暴露原词 LIKE 漏召回，后续章节需要改善检索和对未命中回答的约束。
